TODAY’S FOCUS · 今日只学一件事约 14 分钟

CLIP 的图文对齐思路

学完能够：看懂一张图文相似度表，并解释为什么类别名写成文本后也能参与图像分类。

  • 图像与文本分别编码，但向量进入同一个可比较的空间。
  • 训练时提高配对图文的相似度，降低同批次不配对图文的相对得分。
  • 推理时比较图像与候选文本，选得分最高的文本；它并不生成回答。
01 理解 · 6 分钟 02 小练习 · 6 分钟 03 自测 · 2 分钟

时间按理解、动手与回忆估算；后方选读不计入。练习默认已有 Python 环境。

01 · 理解约 6 分钟

把核心讲清楚

想象桌上有三张照片：猫、汽车、树；旁边有三张写着描述的卡片。今天只研究一件事：怎样让模型给每张照片选对卡片。

第一步：把两种内容变成可比较的向量。 图像编码器看照片，文本编码器读描述；它们各自输出相同维度的向量。训练让正确配对的向量方向更接近。向量不是人工写好的“猫、车、树”属性表，而是模型学出来的表示。

第二步：画一张匹配表。 三张图做行，三段文字做列，每个格子写对应图文的相似度。如果第 i 张图与第 i 段文字配对，正确位置就在对角线上。训练的目标是让正确位置比同一行、同一列里的错误位置更有竞争力，不能简单理解为让所有得分都变大。

核心计算只有一条：$$S_{ij}=\frac{v_i\cdot t_j}{\lVert v_i\rVert\lVert t_j\rVert}$$

$v_i$ 是第 i 张图的向量，$t_j$ 是第 j 段文字的向量；点积表示方向有多接近，分母消除向量长度的影响。$S_{ij}$ 就是匹配表里的一个分数。训练中的缩放与双向损失留到后方选读，今天先看懂这张表。

第三步：把分类改写成选描述。 遇到一张新图，可以把候选类别写成“a photo of a cat”等文本，编码后逐一比较，选得分最高的类别。这就是 CLIP 零样本分类的基本用法：这些类别的分类器不需要再单独训练，但效果仍取决于预训练数据和描述方式。

边界：匹配分数不等于事实证明。 CLIP 擅长图文整体关联；细微的数量、位置或复杂关系仍可能匹配错。下面的二维向量只是帮助理解的人工小例子，不代表真实模型的语义能力。

02 · 小练习约 6 分钟

只做一个最小例子

输入是3个二维图像向量和3个文本向量，均已归一化。先运行下面的标准库代码，确认每张图匹配的文本编号是[0, 1, 2]；然后在计算 scores 之前交换 texts[0] 与 texts[1]。先预测新编号，再运行核对，同时把末尾断言改成你的预期。无需下载数据或安装模型。

images = [[1, 0], [0, 1], [-1, 0]]
texts = [[1, 0], [0, 1], [-1, 0]]
scores = [[sum(a * b for a, b in zip(v, t))
           for t in texts] for v in images]
pred = [max(range(len(row)), key=row.__getitem__)
        for row in scores]
for row in scores:
    print(row)
print("每张图最匹配的文本编号:", pred)
assert pred == [0, 1, 2]
先动手，再对照验收

原矩阵是[[1, 0, -1], [0, 1, 0], [-1, 0, 1]]。交换前两个文本后，预测编号变为[1, 0, 2]，断言也应相应更新。变的是文本列的顺序，图和文字本身的对应关系没有变。

03 · 自测约 2 分钟

合上讲解，回忆两件事

为什么只把所有匹配分数一起变大，并不等于学会图文对齐？
关键是正确配对相对错误配对更有竞争力，而不是整体数值变大。
测试时换一组类别描述，为什么不必再训练一个固定类别分类头？
候选类别本身被文本编码器转为向量，直接与图像向量比较即可。

进阶解释 · 推导、背景与适用边界

相似度到训练目标。 实际训练会给归一化点积乘一个正的缩放因子；官方实现使用 logit_scale.exp()。给批次中配对位置标上标签，然后分别对“每张图选文本”和“每段文本选图”计算交叉熵，取平均。主文的匹配表与原论文的方法部分、Figure 1 和训练伪代码对应；官方实现的 CLIP.forward 可对照特征归一化、矩阵点积与缩放。

一个容易误学的细节。 只有每行 logits 都相等时，该行正确类别的交叉熵才恰好是 log(B)。对随机特征乘以较大的缩放因子，初始化损失不必接近 log(B)。如果扩展为训练且希望学习 logit_scale，优化器必须包含这个参数；仅把它声明为 Parameter 并不够。

不能从本例推出什么。 人工向量交换顺序的练习不含视觉编码器、文本编码器或训练过程，只演示如何读匹配表。图文匹配思路可以启发其他模态任务，但不能据此断言已经解决说话人日志或细粒度时间对齐。

参考实现与代码扩展

下面是交换文本后的参考实现。

images = [[1, 0], [0, 1], [-1, 0]]
texts = [[1, 0], [0, 1], [-1, 0]]
texts[0], texts[1] = texts[1], texts[0]
scores = [[sum(a * b for a, b in zip(v, t))
           for t in texts] for v in images]
pred = [max(range(len(row)), key=row.__getitem__)
        for row in scores]
for row in scores:
    print(row)
print("每张图最匹配的文本编号:", pred)
assert pred == [1, 0, 2]

代码说明与扩展

本例所有输入向量长度都是1，点积就是余弦相似度。若换成任意长度向量，需要先归一化，并处理零向量。若把例子扩展为可训练模型，才需要双向交叉熵和优化器；这些均不属于今日必做练习。
